# 游戏策划文档神器 - CLI完整功能

## 🎉 已实现功能总览

### 核心功能 ✅

1. **访谈系统**
   - 深度访谈，理解需求
   - 生成结构化总结
   - 中文交互

2. **Mail机制** ⭐
   - 紧急邮件（必查）
   - 普通邮件（自主判断）
   - Opinion（影响写作方向）
   - Comment（修改特定章节）

3. **多轮写作系统**
   - 生成文档大纲
   - 逐章节撰写
   - 每轮检查Mail
   - 实时保存进度
   - 自动生成Mermaid图表

4. **审阅闭环**
   - 四维度审阅（逻辑、一致性、实践、可行性）
   - 自动修复critical/major问题
   - 最多3轮迭代
   - 分级问题管理

5. **渐进式上下文管理** ⭐
   - 自动生成章节摘要
   - 按需加载全文
   - 混合上下文构建
   - 缓存机制
   - 上下文清理

### 扩展功能 ✅

6. **网络资料搜索**
   - 搜索相关资料
   - 自动记录引用
   - 生成参考资料章节

7. **本地文档库**
   - 扫描本地Markdown文件
   - 建立文档索引
   - 关键词搜索
   - 引用已有文档

8. **文档模板系统**
   - 预定义模板（游戏策划、产品需求、技术设计、API文档）
   - 快速启动
   - 自定义章节结构
   - 模板化访谈问题

### 辅助功能 ✅

9. **错误处理**
   - API超时自动重试（3次）
   - 网络错误处理
   - 优雅降级

10. **数据管理**
    - 会话状态持久化
    - 决策追踪
    - 邮件存储
    - 摘要缓存
    - 引用管理

## 🚀 使用方式

### 基本命令

```bash
# 列出可用模板
npm run dev templates

# 开始新会话（使用模板）
npm run dev start --template game-design

# 开始新会话（默认）
npm run dev start

# 发送邮件
npm run dev mail

# VS Code预览
npm run preview
```

### 测试命令

```bash
# 基础测试
npm test

# Mail机制测试
npm run test:mail

# 审阅闭环测试
npm run test:review

# 渐进式上下文测试
npm run test:context
```

```
   ↓

   - 四维度审阅
   - 自动修复问题
   - 多轮迭代
   ↓

   - 完整文档
   - 参考资料章节
   - 引用记录
```
